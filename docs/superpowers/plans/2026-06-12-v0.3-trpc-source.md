# v0.3 tRPC source — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `@bridgent/source-trpc` as the v0.3 source-expansion feature and add the minimum source metadata needed for docs and future inspector work.

**Architecture:** Keep Bridgent explicit and source-file based. The tRPC adapter should generate `BridgentTool[]` from an imported router and execute procedures in-process through the tRPC caller API. Queries are exposed by default; mutations require explicit allowlisting; subscriptions are out of scope.

**Source spec:** `docs/superpowers/specs/2026-06-12-v0.3-trpc-source-design.md`.
